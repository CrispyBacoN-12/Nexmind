# Support/resistance zones on /portfolio (+ remove the put card) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the /journal put card, and add code-computed support/resistance zones for every
holding and any ticker on the local-only /portfolio page.

**Architecture:**
- Pure zone math lives in `src/lib/levels/levels.ts`. It takes completed daily candles and
  returns zones and reference lines.
- One local-only route, `GET /api/portfolio/levels`, serves both the summary and the per-ticker
  series.
- A client section with a recharts mini chart renders the result.
- The put-card code is deleted. Its one shared helper, `worstGapDownPct`, moves into
  `src/lib/portfolioRisk/gaps.ts`.

**Tech Stack:** Next.js 16 (read `node_modules/next/dist/docs/` before routes), TypeScript,
node:test, recharts.

**Spec:** `docs/superpowers/specs/2026-11-25-levels-design.md`

### Task 2: Pure zone math

**Files:** Create `src/lib/levels/levels.ts`, `src/lib/levels/levels.test.ts`

**Interfaces:**
```ts
export interface Pivot { kind: "high" | "low"; price: number; t: number; index: number }
export interface Hvn { low: number; high: number; center: number; share: number }
export interface Zone { low: number; high: number; mid: number; touches: number; lastTouch: number | null /* epoch s */; lastTouchIndex: number | null; volumeShare: number; sources: ("pivot" | "hvn")[]; stale: boolean }
export interface LevelsResult {
  price: number; priceT: number; forming: boolean; atr: number | null;
  support: Zone[]; resistance: Zone[]; inZone: Zone | null;   // summary: ≤ 3 each, nearest first
  allZones: Zone[];                                          // qualifying, sorted by mid
  ma50: number | null; ma200: number | null; high52: number | null; low52: number | null;
  note: "shortHistory" | null;
}
export function completedBars(candles: Candle[], nowSec: number): { bars: Candle[]; forming: Candle | null }
export function findPivots(bars: Candle[], side?: number): Pivot[]
export function hvnNodes(bars: Candle[], lookback?: number, bins?: number, minRatio?: number): Hvn[]
export function buildZones(pivots: Pivot[], hvns: Hvn[], atr: number, lastIndex: number): Zone[]   // all zones, sorted by mid
export function computeLevels(candles: Candle[], nowSec: number): LevelsResult | { note: "noData" }
```

Rules:
- `completedBars`: drops the last bar when its America/New_York date equals `nowSec`'s NY date
  and NY time is before 16:00. That dropped bar becomes `forming`.
- `computeLevels`: uses completed bars for every computation. The price is `forming?.c ?? last.c`.
- Fewer than `MIN_BARS` completed bars: reference lines only, empty zones, `note: "shortHistory"`.
- Qualifying zones: `touches ≥ 2 || volumeShare > 0 || lastTouchIndex ≥ lastIndex - RECENT_BARS`.
- Stale: `lastTouchIndex != null && lastIndex - lastTouchIndex > STALE_BARS`. An HVN-only zone is
  never stale.
- Side:
  - support when `high < price`
  - resistance when `low > price`
  - otherwise `inZone`; the nearest one wins when several contain the price
- `ma50` / `ma200`: SMA of the closes.
- `high52` / `low52`: max high / min low of the last 252 bars.

- [ ] **Step 1: Write failing tests** (synthetic candles helper `bar(i, o, h, l, c, v)`, `t = 1_700_000_000 + i*86400`):
  - `findPivots: strict local extremes, last 5 bars excluded`:
    - a V shape with its low at index 10 of 21 bars gives one low pivot at index 10
    - an equal neighbour high is not a pivot
    - a lower low in the last 5 bars is not a pivot
  - `hvnNodes: concentrates volume`:
    - 126 bars with most volume around price 100 → one HVN whose range contains 100
    - share > 0.1
  - `hvnNodes: zero volume → []`
  - `buildZones: joins within 0.5 ATR, caps span at 1 ATR`:
    - pivots at 100, 100.4, 100.8, 101.3 with ATR 1 → the first three join (span 0.8)
    - 101.3 starts a new zone (it would make the span 1.3)
    - touches 3 and 1
  - `buildZones: HVN wider than 1 ATR contributes centre ± 0.5 ATR`
  - `completedBars: drops a bar dated today before 16:00 ET`:
    - now = 2026-11-24T18:00Z (13:00 ET) with the last bar t = 2026-11-24 → dropped, forming set
    - now = 2026-11-24T22:00Z → kept
  - `computeLevels: support below, resistance above, nearest first, ≤ 3`:
    - an oscillating series with clear pivots at 90, 95, 105, 110 and price 100
    - support mids ≈ [95, 90]
    - resistance ≈ [105, 110]
  - `computeLevels: no zone above → none message`: a steadily rising series ending at its high →
    `resistance` is `[]`, the price is the max
  - `computeLevels: short history`: 30 bars → `note "shortHistory"`, zones empty, `ma50` null
  - `computeLevels: stale flag`: the only touches are 300 bars ago → `stale` true

- [ ] **Step 3: Implement.**
  - Zone walk: points are sorted ascending. A point is `{price, kind: pivot | hvn, lo, hi, share, t, index}`.
  - The current zone keeps a running mean of the point prices.
  - A point joins when |price − mean| ≤ 0.5·ATR **and** (max price − min price) after joining is
    ≤ 1·ATR.
  - `low`/`high` = min/max over each point's `lo`/`hi`. For a pivot, `lo = hi = price`. For an HVN,
    use its bounds, clipped to centre ± 0.5·ATR when the bin is wider than 1·ATR.
